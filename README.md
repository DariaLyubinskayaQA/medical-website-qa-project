## 🐛 Зафиксированные дефекты (Bug Reports)

### Bug #1: Несоответствие количества клиник в тексте фактическим данным в выпадающем списке шапки сайта

* **ID:** BG-001  
* **Компонент:** Главная страница / Шапка сайта (Хедер)  
* **Тип:** Content Bug / UI Bug  
* **Severity (Серьезность):** Minor  
* **Priority (Приоритет):** Medium (Высокая видимость на Главной странице)  
* **Окружение:** iPhone 11, iOS 17, Safari Mobile  

#### Шаги воспроизведения (Steps to Reproduce):
1. Открыть главную страницу тестируемого сайта медицинской сети "F-clinic".
2. Изучить рекламный/приветственный текст на баннере: *"в нашей сети 32 клиники в 20 регионах"*.
3. Открыть выпадающий список выбора филиалов в шапке сайта.
4. Пересчитать фактическое количество доступных для выбора регионов и клиник.

#### Фактический результат (Actual Result):
В маркетинговом тексте указано: *32 клиники и 20 регионов*. В выпадающем списке шапки сайта доступно для выбора *35 клиник и 21 регион*. Данные противоречат друг другу.

#### Ожидаемый результат (Expected Result):
Текст на Главной странице должен отображать актуальные данные (35 клиник в 21 регионе), соответствующие реальному наполнению выпадающего списка.
