* **Объект тестирования:** Адаптивная веб-версия сайта сети медицинских центров "F-clinic".
* **Тип тестирования:** Ручное, функциональное, UI/UX (Метод "Черного ящика").

## 🐛 Зафиксированные дефекты (Bug Reports)

### Баг #1: Несоответствие количества клиник в тексте фактическим данным в выпадающем списке шапки сайта

* **Идентификатор (ID):** BG-001 
* **Компонент (Component):** Главная страница / Шапка сайта  
* **Тип дефекта (Type):** Ошибка содержимого (Content Bug) / Ошибка интерфейса (UI Bug)  
* **Серьезность (Severity):** Низкая (Minor)  
* **Приоритет (Priority):** Средний (Medium)  
* **Окружение (Environment):** iPhone 11, iOS 17, браузер Safari Mobile  

#### Шаги воспроизведения:
1. Открыть главную страницу сайта сети медицинских центров "F-clinic".
2. Изучить приветственный текст на баннере: *"в нашей сети 32 клиники в 20 регионах"*.
3. Открыть выпадающий список выбора филиалов в шапке сайта.
4. Пересчитать фактическое количество доступных для выбора регионов и клиник.

#### Фактический результат:
В маркетинговом тексте на странице указано: *32 клиники и 20 регионов*. В выпадающем списке шапки сайта для выбора доступно: *35 клиник и 21 регион*. Данные противоречат друг другу.

#### Ожидаемый результат:
Текст на Главной странице должен отображать актуальные данные (35 клиник в 21 регионе), которые строго соответствуют реальному наполнению выпадающего списка.
