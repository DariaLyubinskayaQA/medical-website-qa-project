# Портфолио QA: Аудит и тестирование веб-сайта медицинской сети

## 📌 О проекте
* **Объект тестирования:** Адаптивная веб-версия сайта сети медицинских центров "Nimof-clinic".
* **Тип тестирования:** Ручное, функциональное, UI/UX (Метод "Черного ящика").
* **Устройство:** iPhone 11 (Экран 6.1", Liquid Retina HD).
* **Цель:** Поиск дефектов логики, интерфейса и контента для улучшения пользовательского опыта (UX).

---

## 🛑 Дисклеймер
Данный проект является учебным и выполнен в рамках практики по обеспечению качества (QA). Тестирование проводилось исключительно на публичной части сайта без вмешательства в исходный код или работу серверов. Все данные обезличены.

## 🐛 Зафиксированные дефекты (Bug Reports)

### Баг #1: Несоответствие количества клиник в тексте фактическим данным в выпадающем списке шапки сайта

* **Идентификатор (ID):** BG-001  
* **Компонент (Component):** Главная страница / Виджет выбора города и филиала  
* **Тип дефекта (Type):** Ошибка содержимого (Content Bug)  
* **Серьезность (Severity):** Низкая (Minor)  
* **Приоритет (Priority):** Средний (Medium)  
* **Окружение (Environment):** iPhone 11, iOS 17, браузер Safari Mobile  

#### Шаги воспроизведения (Steps to Reproduce):
1. Открыть сайт сети медицинских центров "Nimof-clinic".
2. В окне выбора города зафиксировать количество регионов и клиник, доступных в списке городов филиалов.
3. Выбрать любой город.
4. На главной странице ознакомиться с текстом на баннере: «В нашей сети 32 клиники в 20 регионах».
5. Сравнить информацию на баннере с данными из списка городов филиалов.

#### Фактический результат (Actual Result):
В маркетинговом тексте на странице указано: *32 клиники и 20 регионов*. В выпадающем списке шапки сайта для выбора доступно: *35 клиник и 21 регион*. Данные противоречат друг другу.

#### Ожидаемый результат (Expected Result):
Количество клиник и регионов, отображаемое на главной странице и в списке филиалов, должно совпадать.
